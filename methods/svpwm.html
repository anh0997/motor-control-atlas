空間向量脈寬調變（SVPWM）

Space Vector Pulse Width Modulation

📌 一句話理解

三相變頻器只有 8 種開關組合。SVPWM 把命令電壓看成一個旋轉向量，在每個 PWM 週期內，用相鄰兩個主動向量與零向量按時間比例組合出它。

  • 8 種開關狀態 = 6 個主動向量＋2 個零向量，端點構成六邊形。
  • 命令向量落在哪個扇區，就用該扇區兩側的向量合成。
  • 線性區最大相電壓峰值為 Vdc/√3，比 SPWM 的 Vdc/2 高約 15.5%。
  • 實作上等效於「弦波＋零序分量注入」，可用 min-max 法簡化計算。

🧠 控制原理

每個橋臂的狀態以 1（上臂導通）或 0（下臂導通）表示，三相組合 (SaSbSc) 共有 8 種。其中 100、110、010、011、001、101 是六個主動向量 V1～V6，大小皆為 2Vdc/3，彼此相差 60°；000 與 111 是零向量 V0、V7。

依「伏秒平衡」，只要在一個 PWM 週期 Ts 內讓相鄰兩向量各作用一段時間、其餘時間放零向量，平均起來就等於命令向量 Vref。以第 1 扇區為例，常用的七段式順序為 000 → 100 → 110 → 111 → 110 → 100 → 000，每次只切換一個橋臂，降低開關損失。

為什麼電壓利用率較高？SPWM 每相各自調變，相電壓峰值上限是 Vdc/2。SVPWM 等效於在三相同時加入相同的零序電壓：線電壓不變，但相電壓峰值可提高到 Vdc/√3，為 2/√3 ≈ 1.155 倍。

📐 關鍵公式

Vref · Ts = Vk · T1 + Vk+1 · T2 + V0 · T0

伏秒平衡；Vk、Vk+1：命令向量所在扇區兩側的主動向量。

T1 = √3 · Ts · (|Vref| / Vdc) · sin(60° − θr)，   T2 = √3 · Ts · (|Vref| / Vdc) · sin θr，   T0 = Ts − T1 − T2

θr：命令向量在扇區內的角度（0°～60°）；|Vref| 為相電壓峰值（振幅不變）。

m = |Vref| / (Vdc / √3) ≤ 1  ⇒  T1/Ts = m · sin(60° − θr)， T2/Ts = m · sin θr

調變指數 m = 1 對應六邊形的內切圓（線性區上限）；T1 + T2 > Ts 即為過調變。

v0 = −[max(va, vb, vc) + min(va, vb, vc)] / 2，   dx = 1/2 + (vx + v0) / Vdc

min-max 零序注入法，結果與置中排列的 SVPWM 相同；dx：x 相上臂責任比（x = a, b, c）。

🎛️ 互動模擬

拖動命令電壓的角度與調變指數 m，觀察所在扇區、兩個分量向量（平行四邊形）以及 T1、T2、T0。把 m 拉超過 1，在扇區邊界附近會進入過調變。

🔁 控制架構

  1. vα*、vβ*（來自 FOC 或 V/f）
  2. 計算 |Vref| 與角度
  3. 判斷扇區
  4. 計算 T1、T2、T0
  5. 七段式排列 → 三相導通時間
  6. 寫入 PWM 比較暫存器
  7. 三相橋臂開關

SVPWM 只負責「把電壓命令變成開關訊號」，本身不決定轉速或轉矩，常與 FOC 或 V/f 搭配使用。

⚖️ 優點與限制

  • 直流匯流排電壓利用率比 SPWM 高約 15.5%
  • 開關頻率固定，七段式排列每次只切換一個橋臂
  • 數位實作直接，適合在 DSP 中執行
  • 計算量比 SPWM 大（扇區判斷、三角函數）
  • 超過線性區（m > 1）後輸出失真，需另外處理過調變
  • 死區時間會造成電壓誤差，低電流時需要補償

💻 DSP 實作要點

  1. 中心對齊 PWM計數器設成上下計數模式，比較值 = 週期值 × 責任比，即可自然形成對稱的七段式波形。
  2. 用 min-max 法不必計算角度與扇區，只要三相參考電壓的最大值與最小值就能求出責任比，計算量最小。
  3. 限制調變指數若 T1 + T2 > Ts，等比例縮小 T1、T2，避免比較值超出範圍。
  4. 死區設定用 PWM 模組的死區功能設定上下臂延遲，防止直通短路。
