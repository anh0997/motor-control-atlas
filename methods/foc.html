磁場導向控制（FOC）

Field-Oriented Control / Vector Control

📌 一句話理解

把三相電流轉到跟著轉子磁通一起旋轉的 d-q 座標。在這個座標裡電流變成直流量，就能像他激直流馬達一樣，分開控制磁通與轉矩。

  • Clarke 轉換：三相 abc → 兩相靜止 αβ。
  • Park 轉換：αβ → 隨轉子旋轉的 dq，弦波變成直流量。
  • id 控制磁通、iq 控制轉矩，各用一個 PI 控制器。
  • 關鍵是要知道準確的電角度 θe。

🧠 控制原理

直流馬達的磁場與電樞電流天然互相垂直，所以轉矩直接與電樞電流成正比，很好控制。交流馬達的磁場在旋轉、三相電流互相耦合，直接控制很困難。FOC 用座標轉換，把定子電流分解成與轉子磁通同方向的 d 軸分量，以及與它垂直的 q 軸分量。

對表面型永磁同步馬達（SPMSM），轉子磁鐵已提供磁通，通常令 id* = 0，轉矩只由 iq 決定。內藏型（IPMSM）因 Ld ≠ Lq，可配合負的 id 利用磁阻轉矩（MTPA）。感應馬達則需要估算轉子磁通角，例如間接磁場導向利用轉差頻率計算。

電流 PI 控制器輸出 vd*、vq*，經反 Park 轉換回到 αβ 座標，再交給 SVPWM 產生六個開關的訊號。

在互動模擬中轉動 θe：三相電流一直在變，但 id、iq 固定不變。命令與回授都是直流量，PI 控制器就能做到零穩態誤差，這就是 FOC 好用的原因。

📐 關鍵公式

iα = ia，   iβ = (ia + 2 ib) / √3

Clarke 轉換（振幅不變形式），假設三相平衡 ia + ib + ic = 0，因此只需量測兩相電流。

id = iα cos θe + iβ sin θe，   iq = −iα sin θe + iβ cos θe

Park 轉換；θe：電角度 = p · θm（p：極對數，θm：機械角）。

Te = (3/2) · p · [ λf iq + (Ld − Lq) id iq ]

PMSM 電磁轉矩；λf：永磁磁鏈；第二項為磁阻轉矩。SPMSM 的 Ld = Lq，簡化為 Te = (3/2) p λf iq。

vd = Rs id + Ld did/dt − ωe Lq iq，   vq = Rs iq + Lq diq/dt + ωe (Ld id + λf)

PMSM 的 dq 電壓方程式；含 ωe 的項是 d、q 軸之間的耦合，可用前饋補償消除。

🎛️ 互動模擬

拖動電角度 θe 或按「播放」讓座標旋轉；調整電流角 γ 可改變 id 與 iq 的比例。左圖是 αβ 平面上的電流向量與 d、q 軸，右圖是三相電流與 id、iq（虛線）。

🔁 控制架構

前向路徑

  1. 速度命令 ω*
  2. 速度 PI → iq*（id* = 0）
  3. d、q 電流 PI
  4. 反 Park → vα*、vβ*
  5. SVPWM
  6. 三相變頻器
  7. PMSM

回授路徑

  1. 兩相電流取樣
  2. Clarke
  3. Park（使用 θe）
  4. id、iq 回授給電流 PI

編碼器（或觀測器）提供 θe 給 Park／反 Park，並提供轉速 ω 給速度 PI。內層電流迴路快、外層速度迴路慢，是典型的串級控制。

⚖️ 優點與限制

  • 動態響應快，轉矩控制精確
  • 有位置感測時，低速甚至零速也能穩定出力
  • 搭配 SVPWM 開關頻率固定，電流漣波與噪音小
  • 需要準確的轉子角度；感測器增加成本，無感測估測在低速較困難
  • 計算量大：座標轉換、多個 PI、SVPWM
  • 對馬達參數敏感（如感應馬達的轉子時間常數）

💻 DSP 實作要點

  1. ADC 與 PWM 同步把電流取樣觸發設在中心對齊 PWM 載波的谷點或峰點，避開開關切換時的雜訊。
  2. 取得電角度用 eQEP 等模組讀取編碼器，換算 θe = p·θm；或使用無感測觀測器估測。
  3. 三角函數sin、cos 用查表或 IQmath 等定點數學函式庫計算，縮短中斷執行時間。
  4. PI 控制器加入輸出限幅與 anti-windup；電流迴路通常每個 PWM 週期執行一次，速度迴路頻率較低。
  5. 解耦前饋加入 −ωeLqiq 與 ωe(Ldid + λf) 補償，改善高速時的 d、q 軸耦合。
// 每個 PWM 中斷（電流迴路）
read ia, ib                      // ADC
(ialpha, ibeta) = clarke(ia, ib)
(id, iq)       = park(ialpha, ibeta, theta_e)
vd = PI_d(id_ref - id) - we*Lq*iq
vq = PI_q(iq_ref - iq) + we*(Ld*id + lambda_f)
(valpha, vbeta) = inv_park(vd, vq, theta_e)
svpwm(valpha, vbeta, Vdc)        // 寫入比較暫存器
