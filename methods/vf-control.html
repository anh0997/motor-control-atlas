V/f 純量控制（V/f）

Constant V/f Scalar Control

📌 一句話理解

改變供電頻率就能改變轉速；同時讓電壓跟著頻率等比例變化，使磁通維持在額定值附近。

  • 轉速主要由供電頻率決定：ns = 120f / P。
  • 電壓與頻率同比例變化，使氣隙磁通近似固定。
  • 低頻時定子電阻壓降占比變大，需要「低頻電壓提升」補償。
  • 開迴路、不需速度回授，是通用變頻器最常見的控制模式。

🧠 控制原理

感應馬達每相的感應電動勢與「頻率 × 磁通」成正比。若只降頻不降壓，磁通會上升，造成鐵心飽和、激磁電流大增；若只降壓不降頻，磁通下降，轉矩能力變差。因此讓 V/f 維持定值，就能在不同轉速下保持接近額定的磁通與轉矩能力。

當頻率超過基頻（例如 60 Hz）時，變頻器輸出電壓已達額定上限，只能升頻不能升壓，磁通隨頻率增加而下降，進入弱磁區，特性近似定功率。

V/f 是開迴路控制：轉速會因負載造成的轉差而略低於同步轉速，轉矩也無法直接控制。需要時可加入轉差補償，但本質上仍屬於低動態性能的方法。

低頻時，同樣的 V/f 比下定子電阻 Rs 的壓降所占比例變大，實際磁通會下降，使低速轉矩不足，所以要加入 Vboost。提升過多又會過激磁、電流過大。

📐 關鍵公式

E ≈ 4.44 · f · N · kw · Φm  ⇒  Φm ∝ E / f ≈ V / f

E：每相感應電動勢；N：每相匝數；kw：繞組因數；Φm：每極磁通。忽略定子壓降時 E ≈ V。

ns = 120 f / P，   s = (ns − n) / ns

ns：同步轉速（rpm）；P：極數（= 2p）；s：轉差率；n：實際轉速。

V = Vboost + (Vrated − Vboost) · f / fbase（f ≤ fbase）；   V = Vrated（f > fbase）

含低頻電壓提升的 V/f 曲線；fbase：基頻；超過基頻後進入弱磁區。

🎛️ 互動模擬

以 380 V／60 Hz、4 極感應馬達為例。拖動頻率觀察操作點與同步轉速；調整 Vboost 看低頻曲線如何被抬高，超過 60 Hz 後進入弱磁區。

🔁 控制架構

  1. 速度命令 ω*
  2. 加減速斜坡
  3. 頻率命令 f*
  4. V/f 曲線（含 Vboost）
  5. SPWM / SVPWM
  6. 三相變頻器
  7. 感應馬達

頻率命令同時積分成電壓角度 θ = ∫2πf* dt，與電壓大小一起送進調變器。整個架構沒有速度或電流回授（電流只用於保護）。

⚖️ 優點與限制

  • 不需要速度或位置感測器
  • 演算法簡單、計算量小
  • 幾乎不需要馬達參數，通用性高，可一台變頻器帶多台馬達
  • 動態響應慢，無法直接控制轉矩
  • 低速轉矩不足，轉速會隨負載（轉差）變化
  • 急加減速容易過電流，必須限制斜坡

💻 DSP 實作要點

  1. 頻率斜坡每個控制週期依設定的加減速率更新 f*，避免頻率突變造成過電流。
  2. 角度積分與繞回θ += 2π·f*·Ts，超過 2π 就減去 2π，避免定點數溢位。
  3. 電壓命令用查表或線性插值取得 V*，換算為調變指數並限制最大值。
  4. PWM 輸出以 sin 查表產生三相參考，寫入 PWM 比較暫存器（如 TI C2000 的 ePWM 模組）。
  5. 保護用 ADC 讀取相電流做過電流保護與失速防止。
